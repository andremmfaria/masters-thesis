\begin{abstract}
	\addchaptertocentry{\abstractname} % Add the abstract to the table of contents
	Malware's quick growth presents serious cybersecurity concerns, necessitating ongoing innovation in
	methods for detection, analysis, and mitigation. When it comes to handling complex and adaptable
	threats, traditional malware analysis techniques, which mostly rely on manual labour and rule-based
	systems, are progressively less effective. Large language models (LLMs) are a revolutionary
	technology that has the potential to automate malware analysis. Current Artificial Intelligence
	(AI) solutions, including machine learning classifiers and clustering algorithms, concentrate on
	aspects of malware but frequently lack the overall skills necessary to manage intricate datasets
	or fully understand virus behaviors.

	This study suggests using LLMs and Retrieval-Augmented Generation (RAG) to improve the analysis of
	malware, with the specific focus on static analysis. It seeks to automate crucial components of
	malware reverse engineering, such as code analysis, behavior interpretation and anomaly detection,
	by leveraging LLMs' capacity to handle and synthesize massive, heterogeneous information and RAG's
	capability to provide context to this information.

	A dual workflow prototype has been developed to evaluate the effectiveness of LLMs and RAG in
	static malware analysis. In order to support the LLM+RAG workflow a corpus of data was created from
	various reputable sources. This corpus serves as the foundation for training and evaluating the
	LLM+RAG system, ensuring it is equipped with the necessary knowledge to perform effective malware
	analysis.

	The baseline workflow applies the traditional method of static analysis, utilizing tools like
	Ghidra for code disassembly and feature extraction, filtering rules for known malware patterns and
	data comparison with baseline intelligence from sources like VirusTotal. This workflow serves as a
	control to measure the effectiveness.

	The LLM+RAG workflow applies a different method where the features from the malware are extracted
	and a search on the RAG corpus is performed to retrieve relevant information. This process
	leverages the power of LLMs, such as GPT-4o, to understand and synthesize complex data, providing
	richer context and insights for malware analysis.

	The results of the experiments speak for themselves. With a sample space of 20 Windows Portable
	(PE) executable samples across four malware classes (trojan, ransomware, botnet, rootkit), LLM+RAG
	raises category accuracy from 10.0\% (2/20) to 27.8\% (5/18; two abstentions), while delivering
	100\% explanation coverage grounded by \(\geq 2\) citations from the RAG corpus. The time
	efficiency comparison shows a modest latency overhead of +6.4s on average (Baseline = 90.8s;
	RAG+LLM = 97.1s).

	The analysis also includes a composite score combining accuracy, efficiency, and interpretability
	to normalize the comparison results, where the baseline workflow scored 0.28, while the LLM+RAG
	workflow scored 0.43. These results indicate that retrieval-grounded LLMs can add measurable,
	explainable value to static malware triage when paired with guardrails (name redaction, evidence
	thresholding, principled abstention) and a defensible ingestion workflow. Several limitations are
	acknowledged, including a small sample size and reliance on third-party intelligence quality.

	Keywords: Static Malware Analysis, Large Language Models, Retrieval-Augmented Generation,
	Cybersecurity, Explainability, Ghidra, Vector Search, Threat Intelligence, VirusTotal.

	% \end{description}
\end{abstract}
